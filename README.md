## 👨‍💻 About Me

> **Full-Stack Developer · Desktop & AI Video Toolchain Architect**
>
> 专注跨平台桌面应用与音视频 AI 工具链的开源工程实践。核心技术栈：**Rust · TypeScript · Python**，覆盖 Tauri 2.0 桌面端、AI 推理、TUI 终端工具与全栈工程化。
